# Crisis Communications Compliance Checklist

Use this checklist before and after sending incident communications.

## A) Reference & Audit Controls
- [ ] Unique reference code generated and included in all related messages.
- [ ] Timestamp recorded in UTC.
- [ ] Message channel(s) and audience group(s) logged.
- [ ] Acknowledgement evidence captured (email reply, portal ack, API ack, call log).
- [ ] Final archive record linked for audit retrieval.

## B) Review Workflow Controls
- [ ] Technical facts validated by Incident Commander/Ops lead.
- [ ] PR/Crisis wording reviewed by Rosemary Achieng.
- [ ] Legal/compliance-sensitive wording reviewed by Kimberly.
- [ ] Approval trail captured (who approved, when, and what version).
- [ ] Final message version frozen in incident record.

## C) Accessibility Controls
- [ ] Plain-language wording used (minimal jargon).
- [ ] Headings and bullets support screen-reader navigation.
- [ ] Action steps are explicit and numbered.
- [ ] Time references use UTC and exact dates/times.

## D) Multilingual Controls
- [ ] English version published.
- [ ] Swahili version published or queued with owner/time.
- [ ] Additional language needs assessed for affected audience.
- [ ] Translation quality check completed by designated reviewer.

## E) Post-Incident Controls
- [ ] Resolution or false-alarm message published.
- [ ] Post-incident communication review completed within 5 business days.
- [ ] Lessons learned captured and template updates assigned.
- [ ] Compliance artifacts retained per policy.
