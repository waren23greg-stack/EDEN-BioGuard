# PR/Crisis Escalation Guide

This guide defines response timing, escalation actions, and post-incident review for EDEN-BioGuard communications.

**Comms Owner:** Rosemary Achieng (PR/Crisis Manager)  
**Legal Review:** Kimberly (Legal/Compliance)

## 1) Response Timing Standards

- **0-15 minutes (Detection & Triage):**
  - Confirm facts with Incident Commander.
  - Generate a unique reference code.
  - Select one initial template (`incident_detected.md` or stakeholder-specific notice).
- **15-30 minutes (First Release):**
  - Publish first factual communication.
  - Include known impact, immediate actions, and next update time.
- **Every 60 minutes or major status change (Investigation):**
  - Send `ongoing_investigation.md` update.
  - Keep wording consistent with previous updates and the same reference code.
- **At closure:**
  - Publish `incident_resolved.md` or `false_alarm.md`.
  - Include final impact summary and follow-up commitments.

## 2) Escalation Rules

Escalate immediately when any of the following occurs:
1. Severity moves to **HIGH/CRITICAL**.
2. Regulator/government notification thresholds are met.
3. Key stakeholders fail to acknowledge required notices.
4. Public safety or trust risk materially increases.

Escalation flow:
1. Comms lead (Rosemary) updates message draft.
2. Incident Commander validates technical accuracy.
3. Kimberly reviews legal-sensitive language.
4. Executive lead approves critical external statements.

## 3) Message Quality Requirements

Every outbound communication must include:
- Unique reference code
- Clear status label (`DETECTED`, `INVESTIGATING`, `RESOLVED`, `FALSE_ALARM`)
- UTC timestamp
- Audience-specific actions
- Next update time
- Contact/escalation path

## 4) Post-Incident Review (within 5 business days)

1. Review timeline accuracy (first alert timing, update cadence, closure timing).
2. Review acknowledgement rates by audience/channel.
3. Identify unclear language and improve templates.
4. Record legal/compliance observations from Kimberly.
5. Track action items with owner and due date.

## 5) Accessibility & Multilingual Readiness

- Maintain plain-language versions first.
- Publish at minimum in **English (EN)** and **Swahili (SW)** for public-facing notices.
- Keep heading hierarchy and bullet lists consistent for screen readers.
- Avoid abbreviations without first-use expansion.
- Keep sentence length short and action-oriented.
