Layer 1 – Discovery (MISTCODER Core)
MOD-01 – Language‑agnostic ingestion (Python, JS, Go) with secret detection and call‑graph construction.

MOD-02 – Deep static analysis that builds abstract‑syntax trees, control‑flow and data‑flow graphs.

MOD-03 – Embedded dynamic analysis (fuzzing and symbolic execution scaffolding).

Layer 2 – Reasoning (MISTCODER Core)
MOD-04 – AI Reasoning Core that constructs a Threat Knowledge Graph (TKG) from all upstream findings.

Attack Path Finder – BFS/DFS algorithms that produce multi‑step exploit chains with scoring (exploitability, impact, probability, detectability).

ThreatNet – A 22,083‑parameter neural classifier that categorises discovered weaknesses.

Layer 3 – Ecological Intelligence (EDEN)
Real‑time ingestion – Pulls live outbreak alerts from WHO AFRO and Africa CDC RSS feeds and validates them against a structured schema.

BTU Risk Scoring – Joins pathogen incident data with Sentinel‑2 NDVI satellite imagery (ecosystem health proxy) and case counts to compute a Bio‑Threat Unit score.

Geospatial Dashboard – Interactive Folium heatmap with clustered markers coloured by risk tier (LOW/MEDIUM/HIGH).

Synthetic baseline – A 500‑row synthetically generated dataset covering East African countries (Kenya, Uganda, Tanzania, Ethiopia, DRC, Somalia, Rwanda).

Layer 4 – Governance (COVENANT + Trinity Consensus)
COVENANT Engine – A constitutional CI/CD guard that cryptographically chains every scan, maps findings to MITRE ATT&CK, and emits a tamper‑evident audit ledger (SHA‑256 hash chain).

Trinity Consensus – Two‑node canonical voting that certifies every security and ecological finding before it is appended to the blockchain.

Live Chain State – 108 blocks integrity‑verified, 31 ecological events certified, 279,787 tCO₂ at risk flagged, 64 code vulnerabilities documented across East African pilot sites (Mau Forest, Rift Valley, Nairobi Eastlands).
